Electrochemical Sensor Circuit Design

This board-level platform is developed for electrochemical sensor readout, nanoamp-level current measurement, and portable data acquisition. The complete signal chain includes electrochemical bias control, current-to-voltage conversion, high-resolution digitization, embedded data handling, and PC-side visualization.

The goal of this project is to build a complete measurement system rather than only a single analog circuit. The design connects the electrochemical cell, potentiostat, TIA, ADC, MCU firmware, data logging, and upper-computer software into one analyzable platform.

Design Notes

  • Electrode interface: working, reference, and counter electrode connections are separated from noisy digital routing.
  • Potentiostat loop: the reference electrode voltage is sensed with high input impedance, while the counter electrode is driven to maintain the programmed WE–RE bias.
  • TIA input: the inverting input is treated as the most sensitive node and should be protected from leakage, contamination, and long routing.
  • ADC front end: anti-aliasing, reference stability, and input common-mode range should be checked together with the selected ADC configuration.
  • Power tree: analog rails and references are separated from digital switching noise through regulator choice, filtering, and layout strategy.

The PCB layout focuses on low leakage, low noise, and stable mixed-signal operation. The analog front end is placed close to the electrode connector, while digital blocks, display, storage, and power switching circuits are kept away from the TIA summing node.

Analysis Points

  • Linearity: compare measured output voltage with the expected value from the feedback resistor.
  • Noise floor: evaluate the RMS noise and peak-to-peak noise under shorted-input or fixed-current conditions.
  • Stability: check whether the TIA oscillates with different current sources, cable lengths, and input capacitances.
  • ADC effective resolution: convert ADC code noise into input-referred voltage noise and then into equivalent input current noise.
  • Calibration: record gain error and offset error separately so the PC software can apply both slope and vertical-shift correction.

Electrochemical Sensor Output Signal

Electrochemical sensors produce current signals related to the applied potential, analyte concentration, electrode reaction, electrolyte condition, and environmental factors. The output can appear as a steady-state current, transient response, voltammetric peak, or pulse-modulated waveform depending on the test method.

Signal Interpretation

  • Baseline current: indicates background reaction, leakage, and electrode/electrolyte condition.
  • Response amplitude: can be converted to analyte concentration after calibration.
  • Response time: reflects diffusion, reaction kinetics, sensor geometry, and readout filtering.
  • Peak position: helps identify the electrochemical reaction potential in voltammetry measurements.
  • Noise and drift: should be separated from true chemical response through blank tests and repeated measurements.

Potentiostat

The potentiostat controls the electrochemical cell and maintains the desired voltage relationship between the working, reference, and counter electrodes. It enables controlled electrochemical testing such as fixed-potential amperometry, cyclic voltammetry, linear sweep voltammetry, and pulse voltammetry.

  • Controls WE–RE potential through closed-loop counter-electrode drive.
  • Uses the DAC-generated bias as the programmable electrochemical setpoint.
  • Provides the operating condition under which the sensor current is generated.
The reference electrode path should be treated as a high-impedance sensing node, while the counter electrode driver must provide enough output range and current capability to maintain the target bias.

DAC — DAC80502

The DAC80502 generates programmable bias voltages for the potentiostat. This allows the electrochemical operating point to be changed by firmware or PC software instead of fixed resistor dividers.

Role in the System

  • Provides programmable potential setpoints for electrochemical tests.
  • Supports voltage steps, sweeps, and pulse-like bias profiles.
  • Improves repeatability by controlling bias digitally.

Design Considerations

  • DAC reference stability affects absolute bias accuracy.
  • Output filtering can reduce DAC update glitches and digital feedthrough.
  • Firmware should define clear conversion between requested voltage and DAC code.

Transimpedance Amplifier — OPA380

The transimpedance amplifier converts sensor current into a measurable voltage. With a 10 MΩ feedback resistor, the nominal conversion gain is 10 mV/nA.

Gain Relationship

Vout = Vref − Isensor × RF

The sign depends on sensor current direction and the chosen TIA reference voltage.

Stability Considerations

Input capacitance from the electrode, cable, SMU, or protection network can reduce phase margin. Feedback capacitance and layout parasitics must be considered together.

Performance Factors

  • Feedback resistor tolerance and temperature coefficient determine gain accuracy.
  • Op-amp input bias current and current noise affect low-current resolution.
  • Feedback capacitor controls bandwidth and stability.
  • PCB leakage and contamination can become comparable to nanoamp-level signals.

ADC — ADS1262

The ADS1262 is used as an external high-resolution ADC option for digitizing the analog output of the readout chain. It is suitable when the system requires flexible data rate, low-noise conversion, and precise voltage measurement.

  • High-resolution external ADC path for low-level signal digitization.
  • Configurable data rate and digital filtering for noise-bandwidth tradeoff.
  • SPI communication with the MCU for register configuration and data readout.
For low-current measurement, ADC voltage noise can be converted into equivalent input current noise by dividing by the TIA feedback resistance.

ADC — MSP430F6736A

The MSP430F6736A provides an alternative ADC path using the MCU’s integrated 24-bit ADC. This option reduces external component count and simplifies the system architecture when the integrated ADC performance is sufficient.

  • Integrated MCU + ADC solution.
  • Lower component count and smaller board area.
  • Useful for compact or portable sensor readout versions.
