Overall

This project focuses on a portable electrochemical sensor readout platform for nanoampere-level current measurement. The system integrates potentiostat control, programmable DAC biasing, low-current TIA readout, high-resolution ADC acquisition, embedded firmware, and a Python-based PC software interface.

Design goal: build a complete electrochemical measurement system that can bias the sensor, convert the sensor current to voltage, digitize the response, transmit data to the PC, and support CA, CV/LSV, DPV/SWV, and EIS-style measurements.

The MCU controls the DAC and measurement sequence, while the potentiostat biases the electrochemical cell. The sensor is connected to the potentiostat for electrode biasing and to the TIA readout path for current measurement. CSV storage is a PC-software function, while microSD logging is implemented through the MCU.

Hardware Options

TIA Options

OPA380 LMP7721

Two TIA implementations are documented. OPA380 is suitable for precision photodiode/electrochemical current readout, while LMP7721 is intended for ultra-low input bias current and very high impedance sensing conditions.

ADC Options

ADS1262 MSP430F6736A SD24B

The platform supports an external high-resolution ADC path using ADS1262 and an integrated ADC path using the SD24B module inside MSP430F6736A.

Schematic and Layout

This section documents the circuit-level implementation. Each block contains a reserved figure area where schematic screenshots, PCB captures, or measurement screenshots can be inserted later.

Potentiostat

Upload Area: Potentiostat SchematicPlace the WE / RE / CE control schematic here.

Analysis

The potentiostat maintains the required electrochemical bias between the working and reference electrodes while driving the counter electrode. The key design points are loop stability, reference-electrode input impedance, output compliance range, and isolation between bias generation and current readout.

  • Check WE-RE regulation error under different sensor currents.
  • Verify CE output swing does not saturate during high-current response.
  • Evaluate transient response when DAC bias steps are applied.

TIA

Upload Area: TIA SchematicPlace OPA380 / LMP7721 TIA schematic screenshots here.

Analysis

The TIA converts electrochemical sensor current to voltage. With high-value feedback resistance, leakage current, parasitic capacitance, feedback compensation, guard design, and input protection become performance-limiting factors.

  • OPA380 path: precision current-to-voltage conversion and stable low-current readout.
  • LMP7721 path: ultra-low input bias current for very high impedance / low leakage measurements.
  • Recommended test data: input current sweep, output voltage linearity, noise histogram, and step response.

ADC

Upload Area: ADC SchematicPlace ADS1262 and MSP430F6736A SD24B input-path schematics here.

Analysis

The ADC stage digitizes TIA and electrode voltage signals. Important metrics include input-referred noise, offset drift, common-mode range, sampling rate, digital filter setting, and synchronization with DAC updates.

  • ADS1262: external precision ADC path for high-resolution measurements.
  • MSP430F6736A SD24B: integrated 24-bit sigma-delta ADC path for compact system implementation.
  • Recommended test data: shorted-input noise, DC stability, raw-code distribution, and effective resolution.

DAC

Upload Area: DAC SchematicPlace DAC80502 schematic and bias-output measurement data here.

Analysis

The DAC provides programmable electrochemical bias. Since the DAC output directly affects the potentiostat setpoint, bias resolution, reference stability, output noise, settling behavior, and MCU command timing should be characterized.

  • Verify DAC output accuracy across the intended bias range.
  • Measure settling after step changes used in CA, DPV, and SWV.
  • Check whether DAC noise contributes to current noise through the electrochemical cell.

Analysis

Peripheral circuits support display, storage, environmental monitoring, and power management. These blocks should be evaluated not only by function, but also by their influence on analog noise and grounding.

Layout

Upload Area: PCB LayoutPlace top layer, bottom layer, analog front-end close-up, and full PCB renders here.

Layout Analysis

The PCB layout should emphasize low leakage, low noise, and separation between sensitive analog nodes and digital switching circuits. The TIA input node and feedback network are especially sensitive and should be kept short, clean, guarded when possible, and away from SPI/UART/clock traces.

  • Separate analog and digital return paths with controlled connection strategy.
  • Place ADC reference and decoupling capacitors close to the ADC pins.
  • Keep high-impedance TIA input traces short and protected from contamination/leakage.
  • Route DAC and potentiostat signals away from noisy display, SD card, and wireless sections.

TIA Performance

This section compares two TIA choices used for electrochemical current readout: OPA380 and LMP7721. The test-data placeholders are reserved for your measured I-V curves, including input current versus output voltage, linear fitting, residual error, and noise/stability results.

OPA380 TIA

Upload Area: OPA380 I-V CurvePlace measured input-current vs TIA-output-voltage data, fitted gain, residual error, and noise screenshots here.

Reference-Based Device Notes

OPA380 is a precision high-speed transimpedance amplifier family. TI specifies 90 MHz gain-bandwidth, 25 µV offset voltage, 0.1 µV/°C offset drift, and 50 pA input bias current. The datasheet also notes that the TIA signal bandwidth depends strongly on amplifier GBW, input/parasitic capacitance, and feedback resistance, and that the 90 MHz GBW can support greater than 1 MHz transimpedance bandwidth in many configurations.

Analysis for This Project

  • Use the I-V curve to extract transimpedance gain and compare it with the nominal feedback resistor.
  • Check linearity by plotting fitting residuals across the nA current range.
  • Use time-domain noise data to estimate input-referred current noise.
  • Evaluate whether sensor capacitance and feedback capacitance cause overshoot or oscillation.

LMP7721 TIA

Upload Area: LMP7721 I-V CurvePlace measured input-current vs TIA-output-voltage data, leakage comparison, drift, and noise screenshots here.

Reference-Based Device Notes

LMP7721 is designed for extremely low input-bias-current precision sensing. TI lists typical input bias current of 3 fA, specified limits of ±20 fA at 25 °C and ±900 fA at 85 °C, 6.5 nV/√Hz voltage noise at 1 kHz, 17 MHz GBW, 1.3 mA supply current, and 1.8 V to 5.5 V supply operation. TI also highlights its pinout for reducing PCB leakage into the input pins, which is important for high-impedance electrochemical front ends.

Analysis for This Project

  • Use the I-V curve to compare gain accuracy with OPA380 under the same feedback resistor.
  • Focus on leakage and baseline drift, especially when the sensor current is in the low-nA or sub-nA range.
  • Document board-cleanliness and guarding influence because PCB leakage can dominate fA-level amplifier performance.
  • Use long CA baseline data to compare low-frequency drift against OPA380.

Recommended TIA Metrics

I-V GainFit Vout versus input current and report measured Rf-equivalent transimpedance.
LinearityReport R² and residual error across the measured nA current range.
Input-Referred NoiseConvert output-voltage noise to current noise using the feedback resistor.
StabilityShow current-step response or sensor-connected CA baseline to verify no oscillation/ringing.

ADC Performance

This section compares the external ADS1262 precision ADC path and the MSP430F6736A SD24B integrated ADC path. The data placeholders are reserved for your measured input-voltage versus ADC-converted-voltage comparison curves.

ADS1262

Upload Area: ADS1262 Vin vs Converted VoltagePlace input-voltage sweep, ADC converted voltage, fitting line, residual error, and noise data here.

Reference-Based Device Notes

ADS1262 is a precision 32-bit delta-sigma ADC with data rates from 2.5 SPS to 38400 SPS, differential inputs, an integrated CMOS PGA, and 11 multifunction analog inputs. TI lists gain options from 1 to 32, offset drift of 1 nV/°C, gain drift of 0.5 ppm/°C, 7 nVRMS noise at 2.5 SPS and gain = 32, 3 ppm linearity, and a 2.5 V internal reference with 2 ppm/°C drift.

Analysis for This Project

  • Use Vin-versus-converted-voltage data to verify conversion accuracy and linearity.
  • Use residual error to identify gain error, offset error, and possible reference/input-divider error.
  • Compare noise at different data rates and PGA gains if multiple ADS1262 settings are tested.
  • Evaluate whether ADS1262 resolution is limited by ADC noise, reference noise, or TIA output noise.

MSP430F6736A SD24B

Upload Area: SD24B Vin vs Converted VoltagePlace input-voltage sweep, converted voltage, zero-offset calibration comparison, and raw-code data here.

Reference-Based Device Notes

MSP430F6736A is a metering-oriented MSP430 device with three 24-bit sigma-delta ADC channels, a 25 MHz MSP430 CPU, 128 KB flash, 8 KB RAM, LCD support, real-time clock, and UART/SPI/I2C communication interfaces. The MSP430F673x/F672x family datasheet describes up to three high-performance 24-bit sigma-delta ADCs plus a 10-bit ADC, multiple serial interfaces, timers, DMA, RTC, LCD driver, and up to 72 I/O pins.

Analysis for This Project

  • Use Vin-versus-converted-voltage data to quantify SD24B offset and gain error.
  • Compare readings before and after zero-offset calibration.
  • Evaluate whether integrated SD24B performance is sufficient for TIA output voltage resolution.
  • Show raw-code histogram and long-term DC stability for low-current measurements.

PC Software

The PC software is a Python / PySide6 electrochemical workstation GUI. It communicates with the embedded system through UART, parses binary frames or legacy CSV text, displays real-time plots, and records measurement data to CSV.

Upload Area: PC Software Screenshot Place the main Python GUI screenshot here, including connection bar, CA/CV/DPV/SWV/EIS tabs, real-time plots, and CSV controls.

Software Architecture

Communication Layer

  • UART connection with selectable COM port and baud rate.
  • Binary frame protocol using AA 55 header and Modbus CRC16.
  • Backward-compatible parsing of firmware CSV/text output.
  • Command set for DAC control, ADC read, zero offset, CA, CV, EIS, DPV, SWV, stop, ACK, and error handling.

GUI Layer

  • Manual, CA, CV/LSV, DPV/SWV, EIS, and Raw UART tabs.
  • Real-time pyqtgraph plotting for voltage, current, and current-vs-potential curves.
  • CSV logging with raw current, gain-corrected current, TIA voltage, ADC raw code, and environmental data.
  • Independent data buffers for different test modes to prevent plot contamination between measurements.
