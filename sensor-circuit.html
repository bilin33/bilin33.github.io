Overall

This project focuses on a portable electrochemical sensor readout platform for nanoampere-level current measurement. The system integrates potentiostat control, programmable DAC biasing, low-current TIA readout, high-resolution ADC acquisition, embedded firmware, and a Python-based PC software interface.

Design goal: build a complete electrochemical measurement system that can bias the sensor, convert the sensor current to voltage, digitize the response, transmit data to the PC, and support CA, CV/LSV, DPV/SWV, and EIS-style measurements.

Hardware Options

TIA Options

OPA380 LMP7721

Two TIA implementations are documented. OPA380 is suitable for precision photodiode/electrochemical current readout, while LMP7721 is intended for ultra-low input bias current and very high impedance sensing conditions.

ADC Options

ADS1262 MSP430F6736A SD24B

The platform supports an external high-resolution ADC path using ADS1262 and an integrated ADC path using the SD24B module inside MSP430F6736A.

Schematic and Layout

This section documents the circuit-level implementation. Each block contains a reserved figure area where schematic screenshots, PCB captures, or measurement screenshots can be inserted later.

Potentiostat

Upload Area: Potentiostat SchematicPlace the WE / RE / CE control schematic here.

Analysis

The potentiostat maintains the required electrochemical bias between the working and reference electrodes while driving the counter electrode. The key design points are loop stability, reference-electrode input impedance, output compliance range, and isolation between bias generation and current readout.

  • Check WE-RE regulation error under different sensor currents.
  • Verify CE output swing does not saturate during high-current response.
  • Evaluate transient response when DAC bias steps are applied.

TIA

Upload Area: TIA SchematicPlace OPA380 / LMP7721 TIA schematic screenshots here.

Analysis

The TIA converts electrochemical sensor current to voltage. With high-value feedback resistance, leakage current, parasitic capacitance, feedback compensation, guard design, and input protection become performance-limiting factors.

  • OPA380 path: precision current-to-voltage conversion and stable low-current readout.
  • LMP7721 path: ultra-low input bias current for very high impedance / low leakage measurements.
  • Recommended test data: input current sweep, output voltage linearity, noise histogram, and step response.

ADC

Upload Area: ADC SchematicPlace ADS1262 and MSP430F6736A SD24B input-path schematics here.

Analysis

The ADC stage digitizes TIA and electrode voltage signals. Important metrics include input-referred noise, offset drift, common-mode range, sampling rate, digital filter setting, and synchronization with DAC updates.

  • ADS1262: external precision ADC path for high-resolution measurements.
  • MSP430F6736A SD24B: integrated 24-bit sigma-delta ADC path for compact system implementation.
  • Recommended test data: shorted-input noise, DC stability, raw-code distribution, and effective resolution.

DAC

Upload Area: DAC SchematicPlace DAC80502 schematic and bias-output measurement data here.

Analysis

The DAC provides programmable electrochemical bias. Since the DAC output directly affects the potentiostat setpoint, bias resolution, reference stability, output noise, settling behavior, and MCU command timing should be characterized.

  • Verify DAC output accuracy across the intended bias range.
  • Measure settling after step changes used in CA, DPV, and SWV.
  • Check whether DAC noise contributes to current noise through the electrochemical cell.

Peripheral Circuits

Upload Area: Peripheral Circuit SchematicsPlace power, display, microSD, BME280, charger, and regulator schematics here.

Analysis

Peripheral circuits support display, storage, environmental monitoring, and power management. These blocks should be evaluated not only by function, but also by their influence on analog noise and grounding.

  • SSD1306: local status display.
  • microSD: measurement data storage.
  • BME280: temperature, humidity, and pressure monitoring.
  • BQ24074 / TPS61022 / TPS7A4700: battery charging, boost conversion, and low-noise regulation.

Layout

Upload Area: PCB LayoutPlace top layer, bottom layer, analog front-end close-up, and full PCB renders here.

Layout Analysis

The PCB layout should emphasize low leakage, low noise, and separation between sensitive analog nodes and digital switching circuits. The TIA input node and feedback network are especially sensitive and should be kept short, clean, guarded when possible, and away from SPI/UART/clock traces.

  • Separate analog and digital return paths with controlled connection strategy.
  • Place ADC reference and decoupling capacitors close to the ADC pins.
  • Keep high-impedance TIA input traces short and protected from contamination/leakage.
  • Route DAC and potentiostat signals away from noisy display, SD card, and wireless sections.

ADC Performance

This section documents the digitization performance of ADS1262 and the MSP430F6736A built-in SD24B ADC.

ADS1262

Upload Area: ADS1262 Performance DataSuggested figures: shorted-input noise, raw-code histogram, DC input sweep, ENOB table.

Analysis

ADS1262 is the external precision ADC option. The performance analysis should focus on low-noise digitization of the TIA output, reference stability, input filtering, and data-rate/noise tradeoff.

  • Measure shorted-input RMS noise at different sampling rates.
  • Measure DC stability and drift during long-duration CA acquisition.
  • Compare ADC code distribution before and after digital filtering.

MSP430F6736A SD24B

Upload Area: SD24B Performance DataSuggested figures: SD24B offset calibration, noise over time, raw-code histogram, channel comparison.

Analysis

The SD24B path provides an integrated 24-bit ADC solution. It reduces external component count and simplifies the system, but requires careful offset calibration, reference handling, and firmware-side data formatting.

  • Use zero-offset calibration data to show improvement after shorted-input calibration.
  • Compare raw and calibrated current readout stability.
  • Evaluate whether integrated ADC noise is sufficient for nA-level sensor signals.

PC Software

The PC software is a Python / PySide6 electrochemical workstation GUI. It communicates with the embedded system through UART, parses binary frames or legacy CSV text, displays real-time plots, and records measurement data to CSV.

Software Architecture

Communication Layer

  • UART connection with selectable COM port and baud rate.
  • Binary frame protocol using AA 55 header and Modbus CRC16.
  • Backward-compatible parsing of firmware CSV/text output.
  • Command set for DAC control, ADC read, zero offset, CA, CV, EIS, DPV, SWV, stop, ACK, and error handling.

GUI Layer

  • Manual, CA, CV/LSV, DPV/SWV, EIS, and Raw UART tabs.
  • Real-time pyqtgraph plotting for voltage, current, and current-vs-potential curves.
  • CSV logging with raw current, gain-corrected current, TIA voltage, ADC raw code, and environmental data.
  • Independent data buffers for different test modes to prevent plot contamination between measurements.

Implemented Functions Observed from the Uploaded Python File

Function Implementation Summary Portfolio Description
CA Supports fixed potential, duration, sampling interval, and average points. Used for H2 sensor current-vs-time response and long-term stability measurement.
CV / LSV Supports start/end voltage, step size, interval, half-cycles, pause-by-stop, and plot clearing. Used for electrochemical characterization and current-vs-potential response.
DPV / SWV Uses pulse start/end/step/amplitude/interval settings and displays time-domain and I-E plots. Used for pulse-voltammetry hydrogen sensor signal extraction.
EIS Current implementation is a square-perturbation placeholder. Can be presented as an initial EIS-style perturbation module with planned frequency-sweep upgrade.
Calibration Includes SD24B zero-offset command, PC-side gain factor, and additive current offset correction. Useful for explaining measurement correction and ADC/TIA calibration workflow.
Environment Monitor Polls temperature, humidity, and pressure independently when no active scan is running. Supports environmental compensation and sensor-condition recording.
